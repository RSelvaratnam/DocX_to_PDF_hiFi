This is a python script that will print the headings in word documents as bookmarks in a pdf document.  Typically saving to pdf from Microsoft Word, does not convert the headings to bookmarks.

Quick Usage for Running docx2pdf.py  
1.	Move to the directory where the virtual enviroments are setup  
In my case it’s ‘PythonEnvs’ with where I have an environment called "CC_venv". Which is activated by  
2. Run ‘.\CC_venv\Scripts\activate’  
3. Execute the python script docx2pdf.py by typing  "python docx2pdf.py [Input File Path with .docx] [Output.pdf] "
